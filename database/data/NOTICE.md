# Third-party data attribution

`xbom_market_holidays.json` was generated by running
[apptastic-software/trading-calendar](https://github.com/apptastic-software/trading-calendar)
(MIT License, Copyright (c) 2024 Apptastic Software) against MIC `XBOM` (Bombay
Stock Exchange) — see `generate_xbom_holidays.py` in this folder for the exact
script used, which calls straight into that project's own
`trading_calendar.calendar`/`exchange`/`exchanges` classes (backed by the
`exchange_calendars` PyPI package) rather than reimplementing holiday logic.

BankerTrader's production server runs PHP only, so this data is vendored as a
static JSON file and read by pure-PHP code
(`App\Contracts\MarketCalendar\JsonTradingCalendarProvider`) — Python is never
invoked at runtime, only when a developer regenerates this file.

NSE and BSE observe the same SEBI-mandated trading holiday calendar, so this
XBOM data applies to `stocks.exchange = 'NSE'` rows as well as `'BSE'` ones.

**Regenerating / extending the date range:** `exchange_calendars` only ships
holiday data a couple of years ahead, so this file will need periodic
refreshes. On a machine with Python:

```
pip install exchange_calendars==4.13.2 holidays==0.102
python generate_xbom_holidays.py > xbom_market_holidays.json
```

Currently covers 2024-01-01 through 2027-12-31 (generated 2026-09-19); the
source data only had entries through 2026-12-25 at generation time.
